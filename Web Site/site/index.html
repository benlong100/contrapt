Introducing Contrapt:

Freedom to Associate, Again

In 1987, HyperCard let anyone turn ideas into software — cards, buttons, fields, and scripts written in something close to plain English. Contrapt brings that whole idea back: build stacks on your Mac or iPad, run the stacks you made decades ago, and publish any of them to the modern web.

☞ “Oh, that reminds me of…”

That's how thinking works — one idea calling up the next. The original HyperCard brochure called it freedom to associate, and the program delivered something personal computers have rarely offered since: a place where ordinary people made real, working software. A recipe box that dialed the butcher. A field guide with a soundtrack. A choose-your-own adventure written by a nine-year-old. Nobody asked permission, and nobody needed a computer science degree.

Then the web arrived, HyperCard faded, and millions of stacks were stranded on aging floppies and disk images — still full of their makers' art, writing, and cleverness, with nothing modern to run on.

Contrapt is a reimagining of that whole idea, built new for today's Mac and iPad. Cards, backgrounds, buttons, and fields, arranged by dragging and edited in place. Scripts in HyperTalk — the same warm, readable language: go to card 3, put the date into field "Today". Visual effects, paint layers, find, sort. And a message box, of course.

It's not an emulator, and it's not nostalgia under glass — it's the idea itself, given new hardware.

☞ Make stacks

Browse mode runs your stack; edit mode opens it up. Select a button, and the inspector shows its name, style, icon, and script — change the script, click the button, and it just does the new thing. No build step, no project files, no ceremony. The distance between having an idea and clicking on it is measured in seconds.

☞ Rescue your old stacks

Contrapt imports original HyperCard stack files — the structure, the text, the scripts, the 1-bit artwork, the button icons, even the fonts' spirit. Your 1989 address book opens in 2026, buttons still clicking, scripts still running. The gray desktop is exactly where you left it.

☞ Publish to the web

Any stack exports as a self-contained website — the same HyperTalk engine, compiled to WebAssembly, runs your scripts right in the browser. No server code, no accounts, no tracking; host it on any web space you already have.
