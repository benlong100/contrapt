☞ Freedom to Associate, Again

“Oh, that reminds me of…” — that's how thinking often works, one idea calling up the next. The original HyperCard brochure from 1987 called this freedom to associate, and the program delivered something personal computers have rarely offered since: a place where ordinary people made real, working software: a recipe box that dialed the butcher; a field guide with a soundtrack; a choose-your-own adventure written by a nine-year-old. Easy to conceive, easy to build, and nobody needed a computer science degree.

Then the web arrived, HyperCard faded, and millions of stacks were stranded on aging floppies and disk images — still full of their makers' art, writing, and cleverness, but complicated to run on modern hardware.

Contrapt is a reimagining of that whole idea, built new for today's Mac and iPad, complete with cards, backgrounds, buttons, and fields, which you arrange by dragging and editing in place. Tying them together are scripts written in HyperTalk — the same readable language that shipped with the original HyperCard: go to card 3, put the date into field "Today". Visual effects, paint layers, find, sort. And a message box, of course.

It's not an emulator, and it's not nostalgia under glass — it's the original idea itself, given new hardware.

☞ Make stacks

Browse mode runs your stack; edit mode opens it up for tinkering. Select a button, and the inspector shows its name, style, icon, and script — change the script, click the button, and it runs your new code. No build step, no project files, no ceremony. The distance between having an idea and clicking on it is measured in seconds.

☞ Rescue your old stacks

Contrapt imports original HyperCard stack files — the structure, the text, the scripts, the 1-bit artwork, the button icons, even the fonts' spirit. Your 1989 address book opens in 2026, buttons still clicking, scripts still running. The gray desktop is exactly where you left it.

☞ Publish to the web

Any stack exports as a self-contained website — the same HyperTalk engine, compiled to WebAssembly, runs your scripts right in the browser. No server code, no accounts, no tracking; host it on any web space you already have.
